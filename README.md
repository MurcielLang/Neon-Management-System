# 🛒 NeonStore — Inventory Management System

> **A simple inventory management system built with Python, Pandas, and Excel.**

NeonStore is a command-line inventory management system designed to manage supermarket inventory efficiently.

This project was built from scratch as a learning project to practice **Python programming, data processing with Pandas, Excel integration, and Git/GitHub workflow**.

---

## ✨ Features

NeonStore V1 comes with the following features:

### 📦 Inventory Management

* View all inventory data
* Add new items
* Edit existing items
* Delete items
* Automatically generate new item IDs
* Save changes directly to Excel

### 🔎 Search

Search for items based on:

* ID
* Item Name
* Category
* Price
* Stock

### ↕️ Sorting

Sort inventory by:

* Price
* Stock

Supports:

* Ascending
* Descending

### 🔍 Filtering

Filter inventory based on:

* Price
* Stock

Available conditions:

* Greater than
* Less than
* Equal to

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/MurcielLang/Neon-Management-System.git
```

### 2. Navigate to the Project

```bash
cd Neon-Management-System
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
.venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Program

```bash
python src/main.py
```

## 📊 Data Structure

The inventory data is stored in `Inventory.xlsx`.

| Column    | Data Type | Description            |
| --------- | --------- | ---------------------- |
| ID        | Integer   | Unique item identifier |
| Item Name | String    | Name of the item       |
| Category  | String    | Item category          |
| Price     | Integer   | Item price             |
| Stock     | Integer   | Available stock        |
